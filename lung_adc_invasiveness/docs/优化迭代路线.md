# 优化迭代路线

## 1. 迭代的规矩（先定规矩再动手）

1. **一次只改一个东西**。同时改三处，变好了也不知道是谁的功劳。
2. **用训练集交叉验证 AUC（`train_CV_AUC`）挑方案**。它来自训练集 5 折折外预测，测试集完全没参与。
3. **内部测试集只在阶段性节点看**（如课堂讨论 2、期末前），**外部验证集最后只看一次**。
4. **每个实验都留档**：一个 `experiments/<名字>.json` + 一个 `outputs/<名字>/` 文件夹 + 排行榜里一行；
   结论写进下面第 5 节的实验记录表。
5. **差 0.01–0.02 不算提升**。训练集 182 人、测试集几十人，AUC 的 95% CI 宽度在 0.1 以上；
   要么用 DeLong 检验，要么换几个随机种子看是否稳定。
6. **模拟数据上的提升不代表真实数据上的提升**。现在做迭代主要是把“工具”准备好，真实数据到了再正式比较。

## 2. 实验怎么做

```bash
# ① 新建 experiments/<名字>.json，只写要改的参数（键名就是 config.py 里的变量名）
#    例：experiments/v1a_peritumoral.json
#    {"_note": "加瘤周 3mm 影像组学特征", "PERITUMORAL_MM": 3}

# ② 以已有实验为基础，只重跑受影响的步骤（其余结果从基础实验复制过来）
python run_all.py --exp v1a_peritumoral --base v0_baseline --steps 2,4,6

# ③ 看排行榜
python compare_experiments.py      # 生成 outputs/leaderboard.csv 和 outputs/leaderboard.png
```

“改什么 → 重跑哪些步骤”的对照表见 [上手教程.md](上手教程.md) 第 6 节。

## 3. 优化方向全景（按预期收益排序）

### A. 数据层面（收益最大，没有之一）
| 编号 | 思路 | 说明 |
|---|---|---|
| A1 | 拿到真实数据、扩大样本量 | 小样本时任何模型技巧的收益都比不上多 100 个病人 |
| A2 | 多中心 + 外部验证 | 课程 Sec 15 重点：分布漂移、跨机构泛化 |
| A3 | 勾画质量 | 两位医生勾画 + ICC；或用半自动分割（如 nnU-Net、MedSAM）减轻工作量 |
| A4 | 标签定义 | 二分类（AIS+MIA vs IAC）之外可做三分类，或 IAC 内部再分级（WHO 2021 分级） |
| A5 | 多中心特征校正 | ComBat harmonization 消除不同 CT 设备带来的影像组学特征偏移 |

## 4. 第一版迭代（v1）做了什么

v0 → v1 的改动分四块：

1. **实验管理**（让以后的迭代可控）
   - `experiments/*.json`：一个实验一个文件，只写相对 `config.py` 的改动
   - `run_all.py --exp / --base / --steps`：每个实验的结果单独存放在 `outputs/<实验名>/`，只重跑受影响的步骤
   - `compare_experiments.py`：自动汇总所有实验，生成排行榜
2. **B1 瘤周影像组学**（`PERITUMORAL_MM = 3`）：在结节外 3 mm 的环形区域再提一遍一阶 + 纹理特征
   （形状特征对环没有意义，去掉），前缀 `peri_`，和瘤内特征一起进入筛选漏斗。
   依据：浸润性腺癌常伴随毛刺、血管集束、胸膜牵拉等**结节外**改变，瘤内特征看不到。
3. **C1 2.5D 预训练网络**（`DL_BACKBONE = "resnet18_2.5d"`）：取结节中心的轴位、冠状位、矢状位三个切面，
   当成彩色图的 R/G/B 三个通道，输入 ImageNet 预训练的 ResNet18（Lab3 的迁移学习思路）。
   依据：小样本时从头训练 3D 网络容易不稳定，预训练权重提供了现成的边缘/纹理检测能力。
4. **LASSO 选 λ 的规则**（`LASSO_ONE_SE = false`）：用交叉验证误差最小的 λ，而不是更稀疏的 1-SE 规则。

顺带修掉的问题：
- **Grad-CAM 热图偏移**：三次 stride-2 卷积后第 j 个特征格对应输入第 8j 个体素，原来的插值方式让热图整体偏了约 3.5 个体素，现已对齐；弱响应区域改为透明。
- `python run_all.py --fast` 原来会覆盖正式结果，现在默认写到 `outputs/smoke_fast/`，也不进排行榜。

### v1 结果（模拟数据）

**训练集 5 折交叉验证 AUC（挑方案只看这个）**。没有改动的模块是从 v0 复制来的，所以数字相同：

| 模型 | v0_baseline | v1a 瘤周 | v1b 2.5D 预训练 | v1c LASSO λ_min |
|---|---|---|---|---|
| Clinical | 0.855 | 0.855 | 0.855 | 0.855 |
| Radiomics | 0.803 | 0.802 | 0.803 | 0.807 |
| DL (image) | 0.768 | 0.768 | **0.726** | 0.768 |
| DL (image+clinical) | 0.834 | 0.834 | **0.745** | 0.834 |
| Late fusion | 0.852 | 0.848 | 0.825 | 0.856 |
| Nomogram | 0.864 | 0.862 | 0.855 | 0.863 |

**结论：三个改动在交叉验证上都没有带来有意义的提升，默认配置保持 v0。** 三个开关都保留，真实数据到了再重新验证。

最值得记住的一点——**测试集陷阱**：

| | 交叉验证 AUC（该看的） | 内部测试集 AUC（不该用来挑的） |
|---|---|---|
| v1b 的 DL (image) | 0.768 → 0.726 ↓ | 0.701 → 0.750 ↑ |
| v1a 的 Radiomics | 0.803 → 0.802 → | 0.782 → 0.799 ↑ |

如果按内部测试集挑方案，两个都会被“采纳”，而交叉验证说它们没用甚至更差。
测试集只有 78 人，0.05 的波动完全可能是运气。

原因分析：
- **v1a 瘤周**：模拟数据里结节外的信息只有毛刺，而医生已经读出了毛刺征；瘤周特征的 ICC 通过率约 40.3%（瘤内 82%），
  因为环的位置完全取决于勾画边界；LASSO 最终只选进 1 个瘤周特征。真实数据里瘤周有血管集束、胸膜牵拉、周围磨玻璃等改变，可能更有用。
- **v1b 2.5D**：只用三个中心切面丢掉了大部分 3D 信息；ImageNet 的自然图像特征和模拟 CT 的纹理差距大；
  融合版里 512 维影像特征压过了 32 维临床分支，所以“影像+临床”掉得更多（0.834 → 0.745）。
- **v1c λ_min**：13 个特征 vs 5 个特征，AUC 只多 0.004，在噪声范围内。性能相同时选更简单的模型，所以保留 1-SE。

v1 真正落地的是：实验管理（可复现、可比较）、Grad-CAM 对齐修复、三个可切换的选项，以及一套“怎么判断提升是真的”的规矩。

## 5. 实验记录表

| 实验 | 改动 | 主要变化（train_CV_AUC） | 结论 |
|---|---|---|---|
| v0_baseline | — | Nomogram 0.864，Clinical 0.855，Radiomics 0.803，DL 0.768 | 基准 |
| v1a_peritumoral | `PERITUMORAL_MM=3` | Radiomics 0.803 → 0.802 | 不采用 |
| v1b_resnet18_2p5d | `DL_BACKBONE=resnet18_2.5d`，`DL_LR=3e-4` | DL 0.768 → 0.726；DL+临床 0.834 → 0.745 | 不采用 |

## 6. 下一步（v2 候选，按优先级）

1. **换成真实数据后，把 v0 / v1a / v1b / v1c 原样重跑一遍**。每个 json 里的 `_rerun` 就是命令。
   模拟数据上没用的改动，在真实数据上可能有用，反之亦然。
2. **深度学习降方差**：v0 各折验证 AUC 在 0.72–0.83 之间跳，说明 DL 的主要问题是不稳定。
   可以试多随机种子集成、测试时增强（TTA），代价小。
3. **改进 2.5D**：每个方向取多层而不是一层；冻结前几层；骨干网络和分类头分开设学习率；
   融合前给影像特征降维或加 LayerNorm，避免影像分支压过临床分支。
4. **深度特征 + LASSO**：把 3D CNN 倒数第二层的 128 维特征当成“深度影像组学特征”，走和 Rad-score 一样的筛选漏斗。
   这是“深度学习影像组学”文章里另一种常见做法。
5. **影像组学换分类器**：在筛选后的特征上试 SVM / 随机森林 / XGBoost（对应 Week 8 的内容）。
6. **模态缺失实验**：融合网络训练时随机丢掉临床分支，测试缺临床信息时性能掉多少（对应 Sec 15）。
7. **判断提升是否真实的工具**：对两个实验的折外预测做配对 DeLong 检验，换 3 个随机种子重复。

做法不变：一次只改一个 → `experiments/` 里加 json → `run_all.py --base` 只重跑受影响的步骤 → `compare_experiments.py` → 在第 5 节记一行。
