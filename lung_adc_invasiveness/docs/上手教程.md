# 上手教程：从跑通到看懂到改得动

> 写给组里的编程手。按顺序做，大约 1 天能完全上手。每一节最后都有“动手试试”，建议真的去改一下再跑。

---

## 0. 先建立全局印象（10 分钟）

整个项目就是一条流水线，每一步读上一步的输出、写自己的输出：

```
data/raw/（CT、勾画、临床表）
   │  Step 0  00_make_demo_data.py     生成模拟数据（真实数据不用跑）
   │  Step 1  01_preprocess.py         重采样 + 裁结节块 + 分队列 → data/processed/
   ├─ Step 2  02_radiomics_extract.py  提 1000+ 个影像组学特征 + ICC
   ├─ Step 3  03_clinical_model.py     临床模型
   ├─ Step 4  04_radiomics_model.py    特征筛选 + LASSO → Rad-score
   ├─ Step 5  05_deep_learning.py      3D CNN → DL-score（+ 影像+临床融合网络）
   └─ Step 6  06_fusion_evaluate.py    列线图等融合模型 + 全部评价图表
                                        → outputs/<实验名>/figures、tables、results_summary.md
```

记住三个文件就够了：

| 文件 | 作用 |
|---|---|
| `config.py` | **所有可调的东西**：路径、临床变量、窗宽窗位、特征筛选阈值、训练轮数… |
| `experiments/*.json` | 一个实验 = 一个 json，里面写“相对 config.py 改了哪些参数” |
| `run_all.py` | 一键按顺序跑各步骤 |

## 3. 认识数据（30 分钟）

1. 打开 `data/raw/clinical.csv`：一行一个病人，`label` 是病理（0 = AIS/MIA，1 = IAC），`center` 是医院。
2. 打开 `data/processed/meta.csv`：多了 `cohort` 列（train / internal_test / external_test），这就是队列划分。
3. 看 `outputs/v0_baseline/figures/01_qc_patches.png`：每个小图是一个结节的轴位中心层，红线是勾画。
   **真实数据时这张图一定要看**，勾画错位、标签对错人都能在这里发现。
4. 想看三维的 CT：下载免费软件 [ITK-SNAP](http://www.itksnap.org) 或 [3D Slicer](https://www.slicer.org)，
   打开 `data/raw/images/A001.nii.gz`，再把 `data/raw/masks/A001.nii.gz` 作为分割叠加上去。
5. 在 Jupyter 里自己画一个结节块：

   ```python
   import numpy as np, matplotlib.pyplot as plt
   d = np.load(r"data/processed/patches/A001.npz")
   img, mask = d["image"], d["mask"]          # 72×72×72，单位 HU / 0-1
   z = int(np.argwhere(mask)[:, 2].mean())     # 结节中心所在的层
   plt.imshow(np.clip(img[:, :, z].T, -1350, 150), cmap="gray")
   plt.contour(mask[:, :, z].T, [0.5], colors="r")
   ```

**动手试试**：把上面的窗改成纵隔窗 `(-160, 240)`，看磨玻璃成分是不是“消失”了——这就是为什么肺结节要用肺窗。

## 4. 按步骤读代码（2–3 小时）

建议读的顺序和每步的重点：

### Step 1 预处理 `01_preprocess.py`
- **为什么要重采样**：不同医院层厚不同（中心 A 1.25 mm、中心 B 2 mm），不统一的话同一个结节在不同医院“看起来”大小不同。
- **为什么裁 72³ 再随机裁 64³**：训练时随机平移就是数据增强，测试时取正中间。
- **队列划分** `assign_cohorts()`：外部中心整体留作外部验证；其余按标签分层 7:3。
- 改一改：`config.HU_WINDOW`、`config.CROP_SIZE`。

### Step 2 影像组学特征 `02_radiomics_extract.py`
- PyRadiomics 的特征命名：`wavelet-LHL_glcm_Contrast` = 小波 LHL 子带上的 GLCM 对比度。
- **ICC**：两次勾画算出的特征越一致越好，不一致的特征说明对勾画太敏感，不可靠。
- 改一改：`config.RADIOMICS_SETTINGS["binWidth"]`（25 → 50）、`config.PERITUMORAL_MM`（瘤周特征，见 v1）。

### Step 3 临床模型 `03_clinical_model.py`
- `table1()`：论文的 Table 1，连续变量用中位数（四分位数）+ Mann-Whitney U，分类变量用 n(%) + 卡方/Fisher。
- `select_predictors()`：单因素 p < 0.05 → 多因素 → 每次删掉 p 最大的，直到全部 p < 0.05。
- **折外预测** `utils.oof_logit()`：训练集每个人的概率都来自没见过他的模型。融合时必须用这个，不然会过拟合泄露。

### Step 4 影像组学标签 `04_radiomics_model.py`
- `RadiomicsSelector`：筛选漏斗（ICC → U 检验 → 去相关）。终端会打印每一步剩多少个特征。
- `LassoLR`：LASSO + 交叉验证选 λ。`config.LASSO_ONE_SE = True` 选更稀疏的模型（1-SE 规则）。
- 整个筛选 + LASSO 被包进一个 `Pipeline`，所以 `cross_val_predict` 时**每一折都重新筛选**——这是防止“特征筛选泄露”的关键写法。

### Step 5 深度学习 `05_deep_learning.py`
- `NoduleDataset`：数据增强（平移、翻转、旋转）。
- `ResNet3D`：和 Lab3 的 ResNet 是一个思路，只是卷积换成 3D、网络更小（小样本）。`n_clin > 0` 时多一个临床分支，这就是“中间层融合”。
- `train_fold()`：标准训练循环，和 Lab3 几乎一样；多了混合精度（AMP）和类别加权（`pos_weight`）。
- `grad_cam()`：反向传播拿梯度，加权特征图，得到热图。注意上采样时的对齐：三次 stride-2 卷积后，
  第 j 个特征格对应输入的第 8j 个体素，对不齐的话热图会整体偏移几个像素（v1 修过这个 bug）。
  不重新训练、只重画热图：`python src/05_deep_learning.py --gradcam-only`。
- 改一改：`config.DL_EPOCHS`、`config.DL_LR`、`config.DL_DROPOUT`、`config.DL_BACKBONE`（v1 新增 2.5D 预训练）。

### Step 6 融合与评价 `06_fusion_evaluate.py`
- `fit_nomogram()`：临床独立危险因素 + Rad-score + DL-score 做多因素 logistic 回归。
- `evaluate()`：阈值在训练集上用 Youden 指数定好，测试集**沿用**（不能在测试集上再挑阈值）。
- `draw_nomogram()`：列线图是怎么从回归系数画出来的。

| 改动 | 重跑步骤 |

| 影像组学提取（binWidth、滤波器、瘤周） | 2, 4, 6 |

## 7. 新手最容易踩的坑

1. **用测试集调参**：看测试集 AUC 改参数，再看测试集 AUC……测试集就变成训练集了。调参只看排行榜里的 `train_CV_AUC`。
2. **特征筛选泄露**：在全部数据上先筛特征再划分训练/测试——结果会虚高。本项目所有筛选都在训练集内部、而且在交叉验证每一折里重做。
3. **病人级划分**：一个病人有多个结节/多次扫描时，必须按病人划分，不能让同一个人同时出现在训练和测试里。
4. **小样本波动**：几十个测试病人，AUC 差 0.02 往往只是随机波动。看 95% CI 和 DeLong 检验，不要过度解读。
5. **路径有中文**：本项目已处理；自己新写代码时，`torch.save` 要用文件句柄（见 05 里的写法），SimpleITK 读写也尽量通过 nibabel 或内存转换。
